A Dynamic Island for the MacBook notch.

Isle fills the dead space around the camera: what's playing, moving with the actual audio, and what Claude Code is doing — opening on its own when Claude needs you. This page is the reference; the island in the bar above is live.

1 Installing

A private framework and AppleScript automation rule out the Mac App Store, so Isle ships as a disk image. Three steps, and the third is the one worth reading before you start.

  1. Download the disk image.
    Download Isle-0.3.1.dmg 3.2 MB · universal · macOS 14+
  2. Open it and drag Isle into Applications.
  3. Clear the quarantine flag, once.

    Isle is code-signed, but not with a paid Apple Developer ID. macOS therefore quarantines the download and refuses to open it, usually reporting "Isle is damaged and can't be opened." It isn't — that message describes the missing notarisation, not the file. This removes the flag: 

    $ xattr -dr com.apple.quarantine /Applications/Isle.app

    Isle then opens normally, and it does not recur: in-app updates are not quarantined, and a build you compile yourself never carries the flag. What that command actually does →

2 What it shows

Three modes, switched from the menu bar or from Settings. Only the subsystems the active mode needs are started, so a Claude-only install never asks Spotify for anything.

Music

Album art one side of the camera, the waveform the other — reading Spotify's own output, not the system volume. Open it for the transport and a scrubbable playbar.

Claude Code

The marker sits where the album art would be, with the state named on the other side of the camera. No cover to tint from, so the palette markers fall back to fixed colours: amber while building, yellow while thinking.

Both

Each activity takes a side: art and waveform to the left of the camera, marker and state to the right. Here there is a cover to tint from, so the markers take its colours.

3 The marker set

Four of the app's sixteen states are drawn here. Each is a lit pattern, a colour and a motion; select one to send it to the island above. They are designable in the app under Marker Editor — these are the shipped defaults, read out of its source.

4 How it reads your machine

Nothing is inferred. The textbook way to read now-playing is to load Apple's private MediaRemote framework and ask it; around macOS 15.4 Apple gated the read side behind an entitlement third-party apps cannot get, and the call still succeeds — it just returns an empty dictionary.

WhatWhere it comes from
Now playingmediaremote-adapter, loading MediaRemote inside /usr/bin/perl — an Apple-signed binary that does hold the entitlement
Playback controlAppleScript to Spotify
The waveformA Core Audio process tap on Spotify
Claude statusHooks write one JSON file per session; Isle watches the directory
The panelCreated once at full size; only the contents animate, so it never fights the window server

6 Updates and source

Isle checks for updates on launch and on demand. Each release is published alongside a latest.json manifest signed with an Ed25519 key whose public half is compiled into the app, so an unsigned or mismatched update is rejected before installation. 

$ git clone https://github.com/matthewhamilton3141/isle.git
$ cd isle
$ ./scripts/build-mediaremote-adapter.sh
$ open Isle.xcodeproj

A locally built copy is never quarantined, so the xattr step does not apply.
