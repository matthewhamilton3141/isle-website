Stop staring at your terminal. Let your notch do the work for you.

Isle fills the dead space around the camera. It shows what's playing and moves with the actual audio, and it reports what Claude Code is doing — opening on its own when Claude needs you.

Code-signed but not notarised, so macOS quarantines the download and claims the app is damaged. It isn't. Clear the flag once, on first install: 

$ xattr -dr com.apple.quarantine /Applications/Isle.app

The marker set

Four states,
five dots by five.

Each one is a lit pattern, a colour and a motion. Pick a marker and it takes over the island at the top of this page — the one that needs you opens it.

Markers are designable in the app itself, under Marker Editor in the menu bar. The patterns here are the shipped defaults, read straight out of the app's source.

Keeping it current

Updates

Isle checks for updates on launch and on demand. Each release is published as a disk image alongside a latest.json manifest signed with an Ed25519 key whose public half is compiled into the app, so an unsigned or mismatched update is rejected before installation.

Build from source

Locally built copies are never quarantined, so the xattr step does not apply.

$ git clone \
    https://github.com/matthewhamilton3141/isle.git
$ cd isle
# one-time: build the bundled now-playing bridge
$ ./scripts/build-mediaremote-adapter.sh
$ open Isle.xcodeproj  # then ⌘R
Before you download

What it needs.

Isle uses a private framework and AppleScript automation, which rules out the Mac App Store. It ships as a disk image and updates itself from there.

Operating systemmacOS 14 Sonoma or newer
WaveformmacOS 14.4 or newer, for the Core Audio process-tap API
Music sourceSpotify
Claude sourceClaude Code
NotchNot required — on a Mac without one, Isle draws against the top edge
Building from sourceXcode 16 or newer
