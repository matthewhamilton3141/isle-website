Changelog

Twelve releases so far.

Isle checks for updates on launch and installs them itself, verified against a signed manifest. Nothing here needs a re-download once you're running.

0.4.0
2 September 2026
Current
  • An Agenda face. With Calendar or Reminders on, the expanded panel gains a third face: today's date beside what's left of the day — events still to come or in progress and reminders due, each in its calendar's colour, four lines at a time with the rest scrolling. Clicking the date opens Calendar.
  • Events and reminders borrow the island. The way a power event does: an event a few minutes before it starts, with the lead time yours to set, and a reminder as it comes due — then straight back. All-day events and date-only reminders are listed but never announced, declined invitations are skipped, and a moment found late after sleep is dropped rather than announced stale. Both switches default off, so an existing install is never prompted for Calendar access on the strength of an update; Setup offers them to a fresh one.
  • A Pomodoro timer. Opt-in from Settings. A progress ring with the clock inside it, play, skip and reset, and a tally of the cycle; while it runs, the ring and the remaining time sit in the collapsed island beside the music. Breaks roll straight on; the next focus waits to be started. Lengths, intervals per cycle and the end-of-interval chime are all adjustable.
  • Settings gained a fixed sidebar, since it now has more pages than a single scroll could carry.
  • Lighter at rest. The notch no longer redraws itself once a second while a track plays; the Spotify read relaxes to every third second when the panel is closed and the adapter is already reporting Spotify; the album cover is decoded off the main thread and only downloaded when it will be drawn; a paused Pomodoro stops ticking; and a calendar sync is one re-fetch rather than one per changed event.
0.3.2
2 September 2026
  • Setup asks before macOS does. A new step lists the two features that need a permission — the live waveform and device batteries — both ticked, each with its consequence stated. Nothing starts until you continue, so Isle only asks for what you left ticked, and a Claude-only install never sees a Bluetooth prompt.
  • The waveform is Live, Animated or Off. Animated runs the pattern without ever listening, so macOS never asks. Off gives the space back to the album cover. In Settings → Music, where a button opens the Audio Recording pane directly; the device switch gets the same for Bluetooth.
  • Previously the island started before the welcome screen had been read, so the Bluetooth prompt fired in every mode and the audio prompt could arrive while Setup was still open.
0.3.1
2 September 2026
  • Runs on Intel Macs. 0.3.0 was built for Apple Silicon only and would not open on an Intel Mac. 0.3.1 is the same app built for both, and the release script now refuses to package a build that isn't. Nothing else changed.
0.3.0
1 September 2026
  • Lighter while paused. The waveform's audio tap now idles whenever nothing is playing, so a paused Spotify no longer keeps the system's audio engine cycling or Isle analysing silence. Pressing play brings it back in about 30 milliseconds.
  • Power updates are two switches. Battery updates and device updates are independent in Settings, and a switch that is off stops the watching, not just the message.
  • Fixed a restart race that could leave the now-playing feed blank after the screen locked and unlocked, a Done checkmark that could reappear after it had cleared, and an audio tap that started when Spotify launched while music was switched off.

  • The mode switch moved into the menu bar. Music, Claude Code or Both, mirroring the picker in Settings — change it in either place and both agree.

0.2.3
31 August 2026
  • One waveform, one size. The strip narrowed from 26 to 22 when the album shared the island, and because bar thickness came from the strip's width, it quietly drew the bars at a different weight too. The same waveform was being rendered as two objects; now it's one.
0.2.2
31 August 2026
  • "Waiting" can be turned off. It counted as Claude activity, so the moment Claude handed the turn back the island split and the music side shrank. Waiting is the one state you already know about — you are the one being waited on. Off, it stays ambient and the island keeps the music. On by default.
  • The collapsed waveform got its full height. At 14pt inside a 32pt notch, next to a 22pt thumbnail, it read as a ripple under the artwork rather than its counterpart. Silence is unchanged — a taller frame only moves the loud end.
0.2.1
31 August 2026
  • The waveform keeps running while the menu bar item is open. Opening the menu used to take the tracking with it, so the equalizer froze mid-track until you dismissed it.
0.2.0
31 August 2026

Claude bridge

  • One status file per session. The old shared file was last-writer-wins, so a background session's Stop wiped the state of the session you were watching.
  • Urgency ranking. A failed or blocked session outranks one merely working, regardless of write order.
  • Interrupts no longer freeze the island. ESC fires no hook, leaving a working record behind; that record is now retired once the CLI record and the transcript both agree the turn ended.
  • Stopped guessing at silence. The no-response and staleness inferences are gone — Isle has no signal that separates a long think from a stall, so it no longer implies one.
  • API failures land properly. StopFailure is read from the field it actually sends, so rate limits and server errors get their own markers.

Performance

  • The island stopped redrawing itself thirty times a second, and the waveform moved off the redraw path entirely.
  • The waveform reads the music rather than the system volume — and stopped burning CPU doing it.
  • A slow audio system no longer delays launch, and the audio tap is given a moment to come down on quit.

Fixes

  • A long track title actually scrolls now, and scrolls all the way through instead of stopping short.
  • Rewritten README for people installing Isle rather than people handing it off, and an MIT license.

0.1.1
29 August 2026
First release

The island

  • Borderless, non-activating overlay hugging the camera housing, with hover-expand, spring animation, and hit-testing clipped to the drawn shape.
  • Live media sync scoped to Spotify: artwork, marquee title, scrubbable playbar, and an audio-reactive waveform.
  • Shuffle and repeat, read from the Spotify poll and optional in Settings.

Claude Code

  • The hook bridge, the mode archetype (music, Claude, or both), and the designable dot-matrix markers.
  • Distinct error markers per error kind, a live compacting animation, and dismissable alert panels with a pinned mode as an option.
  • The island clears itself when a session ends, and reverts a question that goes unanswered.
